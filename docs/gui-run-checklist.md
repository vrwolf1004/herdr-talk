# GUI 수동 실행 체크리스트

- 인트로에서 Supabase를 고른 뒤 입장을 누른다. **기대 결과:** 저장된 설정이 없으면 Supabase 설정 창이 열린다.
- Supabase 설정을 저장한다. **기대 결과:** 설정이 저장되고 릴레이가 다시 시작되며 채팅 화면으로 이동한다.
- Supabase 설정에서 방 만들기를 누른다. **기대 결과:** 성공하면 서버가 돌려준 방 ID가 방 ID 칸에 들어가고 저장 전 적용 안내가 보인다.
- 방 만들기에 실패하도록 잘못된 설정을 사용한다. **기대 결과:** 실패 이유가 `방 만들기 실패` 메시지로 보이고 방 ID는 바뀌지 않는다.
- 로컬/LAN 모드로 전환한다. **기대 결과:** 이 PC의 ID 칸이 보이지 않는다.
- 인트로에서 Supabase 설정 창을 열고 취소한다. **기대 결과:** 인트로 화면에 남고 첫 실행 선택 화면으로 바뀌지 않는다.
- LAN에서 새 상대와 연결한다. **기대 결과:** SAS 코드는 reveal 교환이 끝난 뒤에만 표시되고, 그 전에는 대기 상태로 보인다.
- 구버전 상대와 연결한다. **기대 결과:** 커밋이 없는 구버전은 거부되며 기존 지문 코드로 대체되지 않는다.
