# Rust 전환과 앞으로의 방향

- 작성: 2026-11-02
- 상태: 1~3단계 구현 완료, 0.7.0 커밋과 보안 리뷰 수정 반영. 첫 릴리스(`v0.7.0` 태그)는 아직 없다. 0.7.0 은 체크섬 서명 없이 낸다. relay 부터 예정.
- 판 구성: `rust/` 가 기본 판, `python/` 은 exe 를 피하려는 사용자용 평문 LAN 판이다. 화면은 같다.

## 왜 Rust 인가

현재 LAN 채팅만 보면 Python 으로도 충분하다. 메시지가 적고, 시간 대부분은 네트워크와 입력 대기다.
전환의 이유는 앞으로의 방향이다.

| 부분 | 효과 | 이유 |
|---|---|---|
| relay 서버 | 큼 | 동시 연결이 많은 상주 프로세스라 `tokio`, `axum` 이 잘 맞고 메모리와 서버 비용이 줄어든다 |
| 암호화 | 중간 | Python 표준 라이브러리에는 종단 암호화 수단이 없다. Rust 는 `rustls`, `snow` 등을 바이너리에 포함할 수 있다 |
| 파일 전송 | 중간 | 추가한다면 스트리밍과 동시 전송에 유리하다 |
| 데스크톱 앱 | 큼 | `talk-core` 를 그대로 `Tauri` 앱에서 쓸 수 있다 |
| 채팅 TUI | 작음 | 체감 속도 차이는 적다 |

Python 설치가 필요 없어지는 것도 이득이다. 대신 OS 별 바이너리 빌드와 릴리스가 필요하다.

## 구조

```text
talk-core (탐색, 메시지, 명령, 번역, 이후 암호화와 relay 접속)
├── herdr-talk: herdr 플러그인. TUI + 도크 연동
└── 데스크톱 앱 (예정): Tauri + 웹 UI
```

도크 연동(`dock.rs`, `herdr_api.rs`)은 플러그인 전용이라 `talk-core` 에 넣지 않는다.

## 단계

1. [x] **Rust 이식.** `talk-core` 와 플러그인으로 나눈다. 평문 형식은 Python 판과 호환된다.
2. [x] **바이너리 배포 준비.** `[[build]]` 설치 스크립트와 태그 릴리스 워크플로. 첫 릴리스는 아직 없다.
3. [x] **암호화.** 인터넷으로 나가기 전에 필수다. 평문 전송은 신뢰할 수 있는 LAN 에서만 쓴다. (구현 완료. 두 PC 실제 확인 전. 설계는 아래 '암호화 설계 결정')
4. [ ] **relay 서버.** 플러그인이 아니라 서버에 따로 띄우는 프로그램이다. 플러그인은 접속만 한다.
   Rust 서버를 직접 운영하는 대신 Cloudflare Workers + Durable Objects 를 쓰는 안도 소규모에서는 더 간단할 수 있다. 착수 전에 정한다.
5. [ ] **데스크톱 앱.** `Tauri` 로 만든다. herdr 없이 대화할 수 있다.

## 판별 차이

| | Rust | Python |
|---|---|---|
| 설치 | 바이너리 또는 소스 빌드 | Python 3 |
| 암호화 | 기본 켜짐 | 없음, 평문 LAN 전용 |
| 서로 대화 | `"plaintext": true` 필요 | 추가 설정 없음 |

## 암호화 설계 결정 (2026-11-02)

- Noise 프로토콜(`snow`)로 메시지를 암호화한다.
- 신뢰: 첫 연결 때 양쪽 화면의 짧은 지문 코드를 비교해 확인하고, 이후에는 저장된 키만 믿는다(TOFU + 지문 확인). 저장된 키와 다른 키는 거부하고 경고한다.
- 기본은 암호화 전용이다. 평문 상대(Python 판)는 사용자가 명시적으로 켰을 때만 허용한다.
- 키를 아는 상대는 어떤 경우에도 평문으로 낮추지 않는다.
- 비밀키는 사용자만 읽을 수 있게 저장하고, 로그와 화면에 내지 않는다.

## 데스크톱 앱에서 달라지는 점

- 도크 연동은 필요 없다.
- 시스템 트레이, OS 알림, 창 관리, 자동 시작을 `Tauri` 로 구현한다.
- 화면은 웹 기술로 새로 만든다. TUI 코드는 재사용하지 않는다.
- Windows, macOS 코드 서명과 자동 업데이트를 고려한다. 서명이 없으면 설치 시 경고가 뜬다.
- 메시지 형식을 맞추면 플러그인 사용자와 데스크톱 사용자가 서로 대화할 수 있다.

## 주의

- `dock.rs` 는 herdr-dock-grid 의 `dock_layout.py` 일부를 옮긴 것이다. Python 플러그인과 레지스트리, 마커, 잠금을 함께 쓰므로 규칙이 바뀌면 두 곳을 맞춘다.
- 릴리스가 없는 버전은 설치에 실패한다. 버전을 올리면 같은 값의 `v` 태그를 푸시해 릴리스를 만든다.
